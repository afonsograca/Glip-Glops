# Glip Glops for Slack

Slack's custom theme has four colours: navigation, selected items, presence and notifications. It colours the window frame and sidebar; the message pane stays Slack's own light or dark grey.

## Install

In the Slack desktop app, go to **Preferences › Appearance**, choose **Custom theme**, and enter the four colours of the theme you want. A theme set on desktop also shows up on mobile.

| Theme | Navigation | Selected items | Presence | Notifications |
| --- | --- | --- | --- | --- |
| **Glip Glops** | `#1F2029` | `#485EDB` | `#32CF72` | `#D81196` |
| **Glip Glops Light** | `#F5F5F5` | `#4155D1` | `#16A34A` | `#BE0A82` |

Use **Glip Glops Light** with Slack's light colour mode. In dark mode Slack replaces a light navigation colour with its own near-black, so it ends up looking like **Glip Glops**.

## One theme per workspace

Themes are set per workspace. To tell workspaces apart, keep **Glip Glops** and change the selected items colour, the one colour Slack always draws as set:

| Accent | Navigation | Selected items | Presence | Notifications |
| --- | --- | --- | --- | --- |
| **Blue** (default) | `#1F2029` | `#485EDB` | `#32CF72` | `#D81196` |
| **Pink** | `#1F2029` | `#D81196` | `#32CF72` | `#DB2C38` |
| **Purple** | `#1F2029` | `#786DC4` | `#32CF72` | `#D81196` |
| **Red** | `#1F2029` | `#DB2C38` | `#32CF72` | `#D81196` |
| **Teal** | `#1F2029` | `#149C92` | `#32CF72` | `#D81196` |
| **Slate** | `#1F2029` | `#55747C` | `#32CF72` | `#D81196` |

Pink uses Red for notifications so mention badges don't blend into the selected item.
